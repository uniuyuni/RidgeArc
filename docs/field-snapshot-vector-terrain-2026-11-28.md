# FIELD β0.9 — 構図スナップショットと地形面描画
2026-11-28 / 実装と一体で管理する仕様書

## 目的と決定
ユーザー承認：「設定した見た目」の保存・復元と、ぼけたドット絵からの脱却を一緒に実装。
従来の「稜線は精密に、風景は豊かに」を継承する。解析の正確さと表示の形状簡略化を分ける。
UI Lab承認済みの基本レイアウト・操作を維持し、共有シート内のみ保存・復元・共有を追加する。

## スナップショット v1
- 単一の状態ソースは FIELD の現行 state と UI 変数。captureFieldSnapshot / restoreFieldSnapshot で変換する。
- field-snapshot.mjs の schema version 1：observer(lat,lon,height), subject(lat,lon,locked,distance), date, minute(JST), view(az,pitch,fov), map(center,zoom), ui(page,split,layers,tracks,compass,coordinates,loupe,splitLoupe,sun), timeline(start,end,days,expanded,lockTime), search(active,body,start,span,direction,days,center,target)。
- 日付は ISO 暦日、時刻は0〜1439分。角度は度、距離はm。JSONの認識済みキーだけを復元。検証が終わるまで現行状態を変更しない。
- 共有シートに名前入力、保存、一覧（風景キャンバスの小型JPEGサムネイル）、復元、共有、確認付き削除を置く。localStorageキー ridgearc.field.snapshots.v1。ストレージ失敗を表示。プレビューは最大320×180程度、風景のみ。地図のクロスオリジンタイルは画像に合成しない。
- URL fragment #snapshot= + URIエンコードされたJSON。別端末で開いて復元。リンクには座標が入るので共有時に明示。サーバー送信・アカウントは不要。既存のデータ・地形モデルには依存するため、ピクセル一致の保証ではない。検索結果・DEM・受光計算・再生中状態・一時ドラッグ状態は保存せず、復元後再計算/再探索する。地図・風景分割比は端末レイアウトに従う。
- 保存時に地形未取得の場合はプレビューにその状態が残るが、復元時の取得は可能。ブラウザデータ削除でローカル保存は消える。バックアップは共有URLを利用。

## 地形：点から面へ
- 旧方式：0.25°方位のレイを画素列へ割り当て、奥行きの異なる色を補間。拡大時に階段状・ぼけた地物が現れる。
- 新方式：既存 projectTerrainRay が返す可視区間を使う。各レイの実測区間を奥行き1.65倍刻みの表示用グループへ分割。未取得を示す退化区間は地物として扱わない。連続する角度区間を統合する。
- 隣接する方位で、同じ奥行き群かつ仰角範囲が重なる区間を四角形に接続。片側だけで検出された地形は方位間の中点へ三角形で閉じる。これは表示上の簡略形状であり、測量された三次元形状ではない。
- 空と地形の境界は既存の実測最高仰角から連続ポリラインを形成、下側を中立色で塗る。遠景から近景の順で面を重ねる。地理院淡色地図由来の水面推定は既知範囲のみ、一定材質色の面として描く。異なる地物の色を混ぜない。輪郭のアンチエイリアスはCanvasの面描画に任せる。面状日照は近似受光点により色を変える。
- 既存の最大120万画素、DPR最大2を維持。makeTerrainTexture は vectorTerrainTexture へ委譲し、風景とルーペの同じ経路を使う。レガシー色補間処理は削除。
- 解析用DEM、稜線仰角、日照、太陽・月の遮蔽は描画面から逆算しない。水面は引き続き表示のみ。
- 奥行き群の刻み、片側三角形の位置、色は暫定の表示方針。元データが拾っていない小地形や細かな形状の網羅性は別問題。固定0.25°方位刻みは変更しない。次段階は高精細DEMの小地形検出と高精細方位の実測、メッシュ境界精度評価。現在の描画は簡略化されたパノラマであり本格的な3Dメッシュではない。

## 回帰試験
- JSON往復、ローカル保存往復、不正データ拒否、未知キー除去。
- 片側地物が三角形、両側連続面が四角形、欠損を岩にしない、海面の角度範囲。
- Chromium：実際のピクセルで背景の山と前景岩の色が混ざらずに区別されること。女岩を実DEMで表示する既存の回帰を維持。
- Chromium：保存、名前、サムネイル、時刻変更、復元、全設定比較、別ページへの共有リンクの復元。
- CI合格は実景との一致・モバイル性能・公開環境反映を保証しない。実際のドット絵解消はユーザーの同一構図での確認が必要。
