# 地形エンジン：稜線は精密に、風景は豊かに
2026-11-28 / FIELD β0.8 第1段階

## 設計原則（ユーザー合意）
- 空と地形の境界および日照・天体遮蔽は角度精度を優先する。
- 岩・島・小地形は形の写実性よりも存在・数・位置・占有面積・概略高さを優先する。三角形程度の簡略形状でもよい。ただし存在を捏造しない。
- 描画と測定値を分離する。表示補間、色、アンチエイリアス、表現上の簡略化から解析用標高を作らない。
- 距離だけでは重要度を決めない。望遠構図の遠景や被写体を重視する。
- 既存操作体系とUI Lab承認済みの表示方式を維持する。新しい見た目の設計は別途合意。

## 第1段階の実装（この変更）
1. 基本地形：β0.7.2の1m DEM/2m距離刻みを800mまで維持（1m DEM未収録時は5m/10mへフォールバック）。遠景の基本タイルを z10 から z12 へ変更。サンプリング距離は従来のまま。
2. 稜線：各方位の基本標高と地球曲率から仰角の局所最大を選ぶ。最大仰角との差0.35°以内、2km以遠、最大3窓。元のサンプリング間隔を踏まえた窓内を z14 の10m DEMで距離15m刻みおよび元の粗いサンプル位置で再取得する。取得できた標高は粗い値に置換。未取得は欠損として扱い、粗い既存値を保持する場合は不確実性を残す。補間で架空の山頂を発生させない。全方位共通で最大192タイル/計算、6並列。複数方位で利用されるタイル優先。上限に達した場合は基礎データへフォールバック。解析・描画に同じ統合済みプロファイルを使う。
3. 風景：画素数上限120万、端末DPR最大2で縦横比を保つ。各画素の水平フットプリントを2〜4点でサンプリングし、色・被覆率を合成する。異なる距離を混ぜて架空の面を生成しない。輪郭の補間は測定値に影響させない。これにより従来単一画素で落ちやすかった細い地物の表示を改善する。
4. 解析用サンプル取得率は従来の基本サンプルで定義し、稜線精細化の取得数とタイル上限は別の統計として保持する。未知の範囲を「可視確定」に変えない。

## 検証
- 実データ：雨晴海岸〜女岩約556m/113.4°。1m DEMに実測サンプル9.55m、視線沿い最高11.92m。β0.7.2の実取得で女岩の550m/0.6°の陸地と描画色を確認。これを退行させない。
- 立山方向の地形について、追加取得したデータの件数と山頂・稜線の変化を確認する。最終的な絶対精度は独立したより細かな断面・実写との比較が必要。
- 合成試験：高さの単純な最大値ではなく仰角で候補を選ぶ。粗い誤ったピークの置換、未知データ、予算上限、描画縦横比、部分被覆を検証する。

## 制約・次段階
- 方位刻みはまだ0.25°。遠方で幅の狭い尾根・近方で細い地物を完全に検出する保証はない。基本サンプルが拾わなかった山頂の探索は別途、DEMタイルの最大標高／占有範囲階層を使った候補検出を検討する。
- 基本放射方向を一律に細分化するのではなく、次は構図・天体交差・標高変化・奥行き境界の近傍だけ追加方位を実測し、解析用稜線と地表表示で共用する。画面空間誤差で必要解像度を判断する。未精細方向では暫定とする。
- 小地形の網羅性はこの段階では既知地形の保持まで。元の標高データの地物検出と位置・面積・最大高さを保持する簡略メッシュは次段階。DEMの解像度を超える岩・樹木・建物は推定や別ソースであることを明示。
- GPU/全面3Dメッシュ化は必要性と性能を比較して判断する。
- 高精細取得に伴う実機メモリ・応答時間・データ量は未確認。稜線精細化の上限・マージンは暫定値。実データ精度検証と負荷測定から調整する。
- 太陽ドラッグ3分刻み、光彩出現時の不連続、ルーペ表示サイズは別課題（UI変更は事前相談）。
