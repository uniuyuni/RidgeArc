# 地形表現・圧縮の比較研究 — 第2回評議会補遺
2026-11-26 / 暫定設計・予備実験
[第2回評議会](technical-design-council-02.md)のGPUタイルメッシュは検証候補に留め、地形表現と描画の採用を保留する。

## 1. 前提
データの地理的区画、保存符号化、展開後の計算表現、空間索引、描画形式は独立した設計変数。標高マップのタイル化はメッシュ保存を意味しない。2.5Dの単一標高面ではオーバーハング、穴、洞窟、橋の下を表せない。完全3Dメッシュ等の局所データを扱える共通RayHit/LOS契約を用意する。単一稜線は単調な遮蔽の場合の高速化に限る。特殊地形の遮蔽区間・円盤方向別の交差を扱う。特殊地形データで穴を埋めたDEMを置換する場合は、有効な置換マスク、基準座標、境界、データ品質を明示する。不完全な点群の空白は穴と断定しない。利用可能な3D測量データ・ライセンスは別途調査。

## 2. 実測した予備比較
手元のGSI DEM5A GML ZIP（FG-GML-533910-DEM5A-20260616.zip内）から、有効33750点の区画を標高標準偏差で並べ、最小と最大を選択。5339-10-91-DEM5A-20251113（777.77–1013.19m）、5339-10-98-DEM5A-20260616（606.32–1199.82m）。どちらも山地で平地ではない。人工丘は z=100+40 exp(-((x-112)^2+(y-75)^2)/4000)。各225×150点。非圧縮float32は135000バイト。試験はPython/NumPy/SciPy/ContourPy/Shapely/zlib、現在のLinux実行環境。元GMLはコミットしない。

方式R：標高を指定刻みで丸め、整数化、2次元差分（左+上-左上予測）をzlib level9で圧縮。復元は2軸累積和、float32化。
方式C：1/5/10mの等高線（ContourPy）を0.05格子単位で折線簡略化、xyを0.01格子刻みに量子化、線ごとの標高と座標、境界標高および全体最小/最大点をzlib圧縮。復号後に非拘束Delaunay三角形による線形補間。曲線方程式・適応等高線・拘束TIN・直接交差の試験ではない。1m間隔の実地形は復元時にNaNが生じたため誤差比較から除外する。
方式D：16×16ブロックのDCT曲面係数、0.01m刻みで係数量子化、低周波順に係数を増やし原格子点の最大誤差が指定値以下になるまで採用（1〜256係数の候補）。ブロックごとの係数数と係数列をzlib圧縮。今回の誤差は復元した格子点上で確認。境界の連続性や直接曲面評価、格子間の誤差上限は未確認。

## 3. 候補拡充と判定
地形に応じて定数/平面、適応曲面（スプライン・ベジェ・低周波係数等）、可変標高刻み/制御点の等高線、誤差制約TIN、誤差制約ラスター、完全3Dメッシュ等を比較。高密度等高線は急斜面で増える。曲面が滑らかな区域では係数方式が有望だが、急峻な地形では予測差分ラスターが有利な今回の結果を尊重。曲面と残差を組み合わせる方式を追加候補にする。既存LERC（最大画素誤差指定）、量子化メッシュも比較。直接計算、必要ブロックだけ復号、全展開して計算、GPU直接評価を同じ精度で比較。圧縮率と計算速度は必ずしも単調なトレードオフではない。実行時に毎回復号せず、アクセス頻度に応じてキャッシュする。

共通の試験指標：保存/通信バイト、展開・索引構築の初期時間、実行時/ピークCPU/GPUメモリ、標高・断面・first-hit・LOS・稜線・天体接触の速度と誤差、連続ピンドラッグ時の実機フレーム、データ境界・欠損・地形トポロジー。圧縮の最大高さ誤差に加えて角度誤差、稜線・山頂・穴の保存を評価する。誤差0.25mは100m先で約0.143度、10km先で約0.00143度（単純小角近似）。描画用と解析用の許容誤差は分ける。標高誤差上限は元DEMとの差であり現実の地形精度ではない。

## 4. 境界契約
タイルの境界を共有する正準地理座標と元地形の辺サンプル、同じ境界補間規則を採用候補とする。各領域を独立近似しただけでは高さの割れ、勾配の不連続、三角形T-junction、等高線接続のずれが起こる。境界制約付き近似、重複帯/halo、LOD境界の接続を比較。共通辺の高さ連続(C0)と斜面法線の連続性は別の検証。実際の断崖まで平滑化しない。見た目だけ隠すskirtは精密遮蔽には使わない。3D置換境界はDEMの埋め残し、穴の誤閉塞、重複面、自己交差を確認。異なる測量成果や欠損は実誤差として記録し、無断で一致させない。境界の実験はまだ行っていない。

## 5. 次の研究
複数地形（平地、海岸、丘陵、丹沢、急崖、人工アーチ）と隣接タイルの固定ベンチマーク、誤差0/0.05/0.25/1/2.5mなどを共通条件とし、R/LERC/曲面残差/適応等高線/TIN/局所完全3Dの比較を進める。Mac M1/Android実機における描画試験と、異種表現の同一RayHit/LOS比較が採用判断の条件。製品実装・方式選定は未決定。
