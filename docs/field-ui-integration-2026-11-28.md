# FIELD β 0.5 — 日照と構図探索のUI統合
ユーザー指摘（2026-11-28）：被写体の日照時間は既存タイムラインへ追加。日時逆探索の数値入力方式では操作が理解できない。機能を別の詳細画面へ押し込んだことが問題。第6回通常UIの基本構造は維持し、探索UIは実計算に沿って修正する。

## 日照
- メインタイムラインの「被写体」ボタンから地図上の受光地点を選択（観測ピンとは別）。選択後は地図・風景表示へ戻り、被写体の日照トラックが自動的にON。選択日ごとの日照区間を太陽可視トラックと同じ時間軸で描画し、未判定と計算待ちを区別。トラック選択メニューで表示/非表示を切替。
- 既存の撮影情報では標高・日照時刻・光量等の数値詳細を確認できるが、別の時間バーは廃止。受光点Workerの計算は共通の結果を購読。選択日と異なる結果はタイムラインに表示しない。
- 複数被写体や被写体名の検索は未実装。1地点のモデル内直射光であり、天候・実景精度の保証ではない。

## 日時逆探索
- 探索→「この構図を撮れる日を探す」→風景上で希望の太陽位置をタップ、または指を動かして指定→期間指定→探索→候補を選択し実際の風景へ移動。
- 通常の太陽・軌跡ドラッグ（時刻変更）とは専用モードで区別。指定時の投影を逆変換して角度を取得。数値角度・許容角は詳細設定に移動。既定期間は選択日から366日以内。
- 撮影地点固定の太陽中心角度探索。G5撮影地点探索、月、精密な重なり条件は未実装。候補は地形欠損・近似・天候未考慮。
- 旧本体・UI Labは変更しない。CIでは日照トラックの自動ON、重複時間バーの削除、風景上の直接指定、候補選択を確認する。タッチ端末での使い心地や実際の配信は別途確認が必要。

## 次のUI設計原則
機能を増やす前に「利用者は何を選び、どこで結果を見るか」を定める。時間に関する結果は既存タイムライン、空間結果は地図/風景、数値詳細は情報、探索条件・候補は探索へ。主操作の成立に専門的な数値入力を要求しない。詳細設定は主操作から分離する。
