## R09 地理情報
- 国土地理院「日本の主な山岳標高一覧（1003山）」2026-03-31版。https://www.gsi.go.jp/kihonjohochousa/kihonjohochousa41139.html 。公式ミラーからCSVを取得し、scripts/import-mountains.mjsで山名・標高・緯度経度を抽出。同名別峰等を含む1059地点、完全重複を除く。public/data/gsi-mountains.json。出典をレイヤー表示。CIで公式CSVと同一内容を照合。元データの表記を保持。規約 https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html 。必要な測量法上の手続きは公開範囲の確定時に確認。
- geographic-labels.mjs: 球面地球で山頂の方位/仰角/距離を計算。既存の観測方位2本のfirstSurface・最高仰角と距離整合を評価。両方が十分手前で遮蔽なら除外、山頂距離に整合する観測点のみ表示。0.25°、最大70km、40〜450mの距離許容は表示用暫定値。未取得部分は可視を保証しない。山頂同定は概算。独立した完全LOSではない。
- 承認済みの「山名・標高」レイヤーと60°引き出し線を使用。重なるラベル・画面外を抑制。名称・標高・距離。位置が変わってもデータは全国分を保持。山名取得失敗を表示。
- 既存のマーカー名: 国土地理院の逆ジオコーディング結果 lv01Nm（町字名）をデバウンス取得。初期の雨晴海岸/女岩は既知名称を維持。外部APIへ入力した地点座標が送信される。失敗時は汎用ラベル、キャッシュ128。HTMLとして挿入せずtextContent。任意POI名・自治体名、地図↔稜線の選択は次段階。CORS・サービスの利用条件/実通信を独立確認する必要あり。合成ブラウザはモック。
## R07 光景再現
- clear-sky.mjs: 球面上の高度80kmまでの標準晴天単一散乱。Rayleigh RGB近似係数、MieのHenyey–Greenstein位相関数、指数密度の仮定、視線と太陽への消散積分、地球による影。仮定の大気（実際のエアロゾル・水蒸気・雲を測定していない）、多重散乱・夜空光・反射は未計算。夜間床は表示上の値。
- 低解像度の空色場（最大64×40）を補間して既存「薄明・空色」に接続、ルーペも同じ計算。2キャッシュ。固定トーンマッピング。既定OFFで従来の空も維持。
- scene-light-engine: 既存の受光面法線と円盤部分遮蔽による相対直射光を使用。大気消散を通る直射RGBと粗い8方向上半球余弦積分の天空散乱光を分離。地形による全方位の天空率未計算、地表反射率は距離色を代理に使用。線形空間で合成し固定表示倍率。暫定値は弱く表示。欠損は従来色、水面は別。観測と絶対放射量の校正をしていない。
- 情報画面に薄明区分、被写体基準の太陽と観測者の水平角（順光45°以下/逆光135°以上/他は斜光）を追加。分類閾値は暫定。ゴールデンアワーの独立トラック、地域の日照地図、水面反射、完全な光学再現は未実装。透明度・気象予測は優先順変更により後回し。
## R03 / R02 撮影地点探索の実計算試作
- location-geometry: 球面弧長・端点高さから方向を求め、端点を結ぶ直線の半径を計算して有限LOS。既知サンプルの明確な遮蔽、サンプル上可視、未知を区別。空間連続面・大気差・植生建物は未検証。
- G5: 固定被写体、指定日または1〜7日、指定時刻または前後0〜30分、5分間隔（指定時刻も含む）。局所太陽の反対方位±1°（5本）上を50m以上の距離間隔でサンプル、上限30km/2400候補、地表DEMを取得。候補地点で再度太陽方向と被写体角距離を比較、円盤半径+許容角。上位64候補の有限LOS（10〜180m可変間隔）と別の太陽円盤遮蔽（3方位・70kmまで）を評価。選別で落ちた候補や未サンプル位置の解を否定しない。太陽/被写体可視と配置一致は別。
- G4: 指定日の中心と半径100〜5000m、最大81グリッド候補。地点ごとの見かけ太陽円盤下縁ではなく**上縁**が海面基準の幾何学的dipへ達する最終接触時刻を近似モデルで算出。直前20分を5時点・各3方位でDEMサンプリングし、地平線近傍の遮蔽物を判定。これは厳しめのサンプル回廊判定で、全時間・全円盤の可視を証明しない。海の標高欠損をゼロに補わないので、海岸の候補が不明になる場合がある。地球曲率近似、屈折モデル限界、70km上限。
- 共通地形取得 sampleElevationBatch。DEM 5m/10m、遠景は粗いタイル。近景精度の本体1mとは別の試作。未知・上限を明示。Worker、最新リクエストのみ/停止、90秒停止監視。計算結果のステータスは暫定。候補なし≠解なし。
- UI Lab /ui-lab/location-search.html。地図クリック・ピン移動、条件入力、結果ピン、FIELDへのスナップショットリンク。従来FIELD探索UIへ統合しない。新UIはユーザー確認が必要。候補をFIELDに渡した時、任意被写体地上高はFIELDの既存被写体モデルには保存されない（裸地へ戻る）。R02の全域可視/逆可視地図・断面、広域探索ヒートマップ、アクセス検証は未完成。G4/G5は実装試作であり精密・網羅的な最終機能ではない。
## 検証
単体試験、Chromiumの合成DEMと実GSI。山岳カタログ原典と一致、実DEM山頂候補と描画、原色赤のピクセル、天空レイヤー、スナップショット互換、G4/G5試作、欠損。物理精度・現場での撮影成功・モバイル性能・外部公開反映とは区別。元の評議会の検証計画を継続。
