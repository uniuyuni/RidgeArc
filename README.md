# RidgeArc

稜線と太陽・月の軌跡から未来の風景を読む撮影計画ツール。

初期プロトタイプは日本国内の国土地理院標高タイルをブラウザで取得し、太陽の軌道と地形の遮蔽を表示する。実験版であり、撮影時刻や安全を保証しない。

## Cloudflare

Workers の Static Assets として `npx wrangler deploy` で配置する。Pages を利用する場合はビルドなし、出力ディレクトリ `public`。ローカルでは `python3 -m http.server 8000 --directory public`。

## P0 と今後

- P0: 座標・日付、方位角と仰角の等角度表示、距離帯別稜線、太陽円盤と軌跡、時刻スライダー、地形遮蔽の概算。
- 今後: 地図ピン、月、高精度DEM/長距離地形、カメラ投影、樹木・建物、地点別の日照と天空光、気象・夕焼け予測。
- 丹沢湖の初回実地検証: 撮影地点は第2展望台の可能性があるが未確定。地形の見かけ、植生、湖面の先行暗化、直接光と天空光の区別が課題。写真や元データは公開しない。

出典: [国土地理院 標高タイル](https://maps.gsi.go.jp/development/demtile.html)。
